# 🌍 Personal Travel Blog

A simple, static travel blog website built entirely as a frontend project.

---

## 🛠️ Tech Stack
* **HTML5** (Structure and content)
* **CSS3** (Layout, design, and responsive web design)

---

## 🚀 How to Run
Since this project does not use any JavaScript or backend, no installation is required:

1. Download the project as a ZIP file or clone it via Git.
2. Open the project folder.
3. Double-click the `index.html` file to open it in any modern web browser.
