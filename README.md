# Travel Blog – Responsive Frontend Website

Travel Blog is a fully responsive multi-page website developed as a collaborative team project using HTML and CSS. The project focuses on modern frontend development, advanced responsive design techniques, CSS animations, and creating a visually engaging user experience without using JavaScript.

The website presents multiple travel destinations across five individual pages, featuring clean layouts, smooth animations, interactive content sections, and modern UI components. Special attention was given to responsive behavior across desktop, tablet, and mobile devices, ensuring a consistent experience on all screen sizes.

Throughout the project, CSS was pushed beyond the basics by implementing advanced layouts, transitions, animations, interactive hover effects, and expandable content sections using the native HTML `<details>` and `<summary>` elements.

## Key Features

* Fully responsive multi-page website
* Five individually designed destination pages
* Modern travel blog layout
* Advanced CSS animations and transitions
* Responsive navigation
* Interactive expandable content using `<details>` and `<summary>`
* Clean and reusable HTML/CSS structure
* Optimized layouts for desktop, tablet, and mobile devices
* Team-based development workflow
